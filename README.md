# JC.Carvajal.Dev — Portafolio web

Portafolio personal de Julio Contreras Carvajal: proyectos y plantillas de sitios web.

## Estructura

```
index.html          Portada
proyectos.html      Lista de proyectos
css/, js/           Estilos y scripts
proyectos/          Plantillas de proyectos (01 a 06)
```

## Ver en local

Abre `index.html` en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
npx serve .
# o
python -m http.server
```

## Publicar

Sitio estático. Guía completa en [`COMO-PUBLICAR.md`](COMO-PUBLICAR.md).
Recomendado: Cloudflare Pages conectado a este repo, o Netlify (deploy por drag & drop).
